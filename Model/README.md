# Machine Learning Model

This directory contains the complete machine learning pipeline developed for the Wearable Human Activity Recognition System, including dataset preparation, signal preprocessing, model development, training, and evaluation.

The system uses a **1D Convolutional Neural Network (1D-CNN)** to classify human activities based on six-axis inertial measurement data acquired from an MPU6050 sensor.
