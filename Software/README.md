# Software Implementation

This directory contains the software components developed for the Wearable Human Activity Recognition System.

The software is responsible for acquiring motion data, establishing wireless communication, recording sensor measurements, processing incoming signals, and performing real-time activity classification.

The implementation combines embedded programming on the ESP32-C3 with a Python-based desktop application.
